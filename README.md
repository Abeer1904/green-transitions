# Gram Urja — independent green transitions site

A standalone React site, separate from the SMART app. Its learning model adapts Learn → Test → Build → Pathways to individual and village journeys in Malai.

## Run

`npm install`, then `npm run dev`. Open http://127.0.0.1:3013.

`npm run build` checks TypeScript and bundles the static site into `dist/`. `npm test` checks evidence privacy, backup validation and the separation of learning from project readiness.

## Included

- Technology-specific 0→1 maps: needs, feasibility, ownership, implementation, operation and sustained service. Individual and village views reveal skills, people, requirements and outputs. This is not a year-long course.
- Biogas and solar lessons, decision exercises, quizzes and role matching.
- Field challenges with self-reported evidence and explicit sharing into the village draft.
- Draft CV text download, role exploration and private participation-support preferences.
- Village plans and JSON export excluding private individual information.
- Private JSON backup and validated restore.
- Optional read-only browser tool `read_journey_summary` (no personal content).

## Deliberate limits

Drafts exist in memory until a backup is downloaded; reloading loses unsaved work. There is no server database, multi-user village record, formal assessment, certification, booking or placement integration. All evidence remains unverified. Source content is adapted from the supplied directory, not a verified source of current schemes, prices or eligibility. Water, gasification and regenerative agriculture require additional content.

# Scientific scene and interface revision
Visual thesis: a calm field manual, using precise cross-sections, mineral colours and generous working space.
Content plan: orient the learner; choose a technology; explore the system; connect its components to roles and village decisions.
Interaction thesis: animated paths explain direction only; flow focus isolates a circuit; explicit stage selection changes planning / construction / operating state. Motion respects pause and reduced-motion preferences.

Biogas uses a fixed-dome reference arrangement, including inlet, gas headspace, submerged outlet, compensation chamber, gas valve and condensate drain. Solar uses one off-grid irrigation example with PV, controller, submersible pump, tank and irrigation. These are conceptual schematics, not dimensioned installation plans. Gas treatment, electrical protection and control details vary with the design and must be specified professionally.

Technical references:
- GTZ/GATE ISAT, Biogas Digest Volume II: https://energypedia.info/images/2/2c/Biogas_gate_volume_2.pdf
- FAO/GACSA solar irrigation practice brief: https://www.fao.org/fileadmin/user_upload/gacsa/docs/GACSA_Practice_brief_SolarIrrigation_v5.pdf

The Green Skill Directory remains the learning content basis. Diagram flows are qualitative, not predictions of output or performance.

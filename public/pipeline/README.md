# Green Gram Project Pipeline

Open `index.html` directly in a browser. All scripts, icons and illustrations are local; no development server or installation is required.

This is an interactive pitch prototype, with illustrative project concepts and AI-generated concept images. It is not a live directory or a validation of costs, financing or viability.

## Included

- A searchable project grid with state, district, village, sector and support filters.
- Project pages with the nine-field framework, contributions, partner asks and next studies.
- Saved projects and editable nine-field drafts, stored in this browser.
- Local partner offers, product proposals and experience contributions, visible in the workspace.
- Plain-text draft download.

Drafts and offers are not published or sent. Browser storage can be cleared by browser settings and is specific to the browser and file/origin. A shared pilot would need organisation accounts, a database, publication review, uploaded evidence and actual partner messaging.

The original Commons prototype and the practice website are unchanged. `check.mjs` is a local Playwright verification script; its Playwright and Chrome paths reflect this machine. Screenshot files are review outputs, not website dependencies.

Icons: Lucide 0.468.0 (ISC license), bundled locally. Images: AI-generated concept illustrations created for this prototype.
